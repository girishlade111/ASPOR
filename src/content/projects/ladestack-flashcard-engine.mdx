# LadeStack Flashcard Engine

## Algorithmic Mastery & Mechanical Discipline
A spaced-repetition cognitive accelerator built to bridge the gap between mechanical engineering thermodynamics and complex software systems concepts.

### Technical Architecture
- **Modified SM-2 / Leitner Algorithm**: Dynamically calculates memory decay curves based on response latency and accuracy telemetry.
- **Offline-First Persistence**: IndexedDB client engine with bi-directional conflict-free replicated data types (CRDTs).
- **Tactile Kinematics**: Micro-interactions animated with GSAP physics-based easing to provide satisfying cognitive reinforcement.

### Verified Retention Metrics
Users practicing complex algorithms and distributed systems designs retained over **92% core conceptual recall** after 30 days of active session pacing.
